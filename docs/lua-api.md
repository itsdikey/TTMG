# TTMG Lua API

TTMG runs Lua scripts with a small set of host commands. The canonical way to call
them is through the `ttmg` table:

```lua
local name = ttmg.prompt_input("Enter your callsign:", "Maverick")
ttmg.print("Hello, " .. name)
```

For backwards compatibility every command is *also* registered as a flat global, so
existing scripts that call `prompt_input(...)`, `print(...)`, and so on keep working
unchanged. Both names resolve to the same function.

The legacy global names are: `get_config`, `get_secret`, `print`, `prompt_input`, `prompt_select`, `run_process`, `run_shell`.

## Commands

### `ttmg.get_config(key)`

Reads a value from the config.yaml file next to the script.

**Parameters**

- key: The configuration key to read.

**Example**

```lua
local region = ttmg.get_config("region")
```

### `ttmg.get_secret(name)`

Retrieves an encrypted secret from the store.

**Parameters**

- name: The name of the secret to retrieve.

**Example**

```lua
local token = ttmg.get_secret("github_token")
```

> Requires access to the encrypted secret store. TTMG asks for the store
> password once before running the script.

### `ttmg.print(text)`

Prints text to the console. Spectre.Console markup such as [red]text[/] is supported.

**Parameters**

- text: The text to print.

**Example**

```lua
ttmg.print("[green]Hello, world![/]")
```

### `ttmg.prompt_input(title[, default])`

Displays a text input prompt and returns the entered string. When a default is supplied it is shown and returned on Enter.

**Parameters**

- title: The prompt shown to the user.
- default (optional): Value returned when the user presses Enter without typing.

**Example**

```lua
local name = ttmg.prompt_input("Callsign:", "Maverick")
```

### `ttmg.prompt_select(title, options)`

Displays a selection menu and returns the chosen option.

**Parameters**

- title: The prompt shown above the options.
- options: A Lua array of option strings.

**Example**

```lua
local task = ttmg.prompt_select("Objective:", { "Scan", "Return" })
```

### `ttmg.run_process(command, args, detached)`

Runs an external process with arguments.

**Parameters**

- command: The executable to run.
- args: The command-line arguments string.
- detached: true to launch without waiting; false to wait for the process to exit.

**Example**

```lua
ttmg.run_process("cmd.exe", "/c dir", false)
```

### `ttmg.run_shell(command, detached)`

Runs a command using the default shell configured in scripts.yaml.

**Parameters**

- command: The shell command to run.
- detached: true to launch without waiting; false to wait for the process to exit.

**Example**

```lua
ttmg.run_shell("echo hello", false)
```
